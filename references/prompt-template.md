# 配图提示词模板

按当前需求选用字段，不必把空字段或内部工作记录发给图像模型。明确的用户要求优先。

```text
Use case: ads-marketing / stylized-concept
Asset type: [使用位置与比例]
Core message: [观众应该理解的一句话]
Scene: [用一个物理场景表达冲突和后果]
Subject and relationship: [主体、障碍、结果分别是什么，彼此如何关联]
Style: premium 3D editorial illustration / cinematic commercial visual
Composition: [视觉中心、镜头、景深、留白]
Materials: [承担表达作用的材质与表面细节]
Lighting: [主光方向、阴影和氛围]
Palette: [主色与少量强调色，以及各自的作用]
Text (verbatim): [准确文字、位置与字形；无字时写 no text]
Preserve: [使用参考图或修改已有图片时需要保留的部分]
Avoid: [与这张图有关的多余元素、失真、额外文字或虚构证据]
```

检查提示词时，重点问：

- 删掉标题后，物件之间的关系还成立吗？
- 指定的材质、光线和镜头是在强化观点，还是只在堆术语？
- 是否给了图像模型互相冲突的要求？
- 哪个细节决定这张图适合这段文案？

延续系列图时，保留镜头语言、主色、材质与光线方向，改变表达观点所必需的场景关系。
